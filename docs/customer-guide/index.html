คู่มือสำหรับลูกค้า

คู่มือการใช้งาน PropFlow

ระบบจัดการบ้านเช่าผ่าน LINE — ชำระบิล แนบสลิป ดูเอกสาร แจ้งซ่อม และชุมชนลูกบ้าน ในที่เดียว

สารบัญ

  1. ใครใช้ระบบอะไรบ้าง
  2. คู่มือเจ้าของบ้านเช่า (Owner)
  3. คู่มือผู้เช่า (ผ่าน LINE)
  4. ตรวจสลิปและ OCR
  5. ประเภทบัญชี และการเปลี่ยนเป็นถาวร
  6. คำถามที่พบบ่อย

1. ใครใช้ระบบอะไรบ้าง

PropFlow แยกหน้าจอตามบทบาท เพื่อให้แต่ละคนเห็นเฉพาะงานของตน

เจ้าของบ้านเช่า (Owner) จัดการอาคาร ห้อง ผู้เช่า ออกบิล ตรวจสลิป แจ้งซ่อม ชุมชน — ผ่าน Web Portal หรือ LINE
ผู้เช่า (Tenant) ชำระเงิน ดูเอกสาร แจ้งซ่อม ชุมชน — ทำทั้งหมดผ่าน LINE OA โดยไม่ต้องจำรหัสผ่าน
ผู้ดูแลแพลตฟอร์ม (Admin) สร้างบัญชีเจ้าของ กำหนดประเภทบัญชี (เดือน/ปี/ถาวร) มอบหมายทรัพย์สิน
ช่องทางเข้าใช้ Portal บนคอม: /portal/login
ผู้เช่า: เปิดจากเมนูในแชท LINE OA

2. คู่มือเจ้าของบ้านเช่า (Owner)

หลังได้รับ Username/Password จากผู้ดูแล ให้ล็อกอิน Portal แล้วเริ่มจัดการอสังหาฯ ของคุณ

ภาพตัวอย่างหน้าภาพรวม — เห็นสลิปรอตรวจ ค้างชำระ และงานแจ้งซ่อม

ขั้นตอนเริ่มต้น

  1. เปิดลิงก์ Portal ที่ได้รับ → ล็อกอินด้วย Username / Password
  2. ถ้าระบบบังคับเปลี่ยนรหัสผ่าน ให้ตั้งรหัสใหม่ทันที
  3. (แนะนำ) เปิดลิงก์ผูก LINE เพื่อรับแจ้งเตือนสลิป/งานด่วนใน LINE
  4. ตรวจว่ามีทรัพย์สินถูกมอบหมายแล้ว จากเมนูภาพรวมหรือรายการอาคาร

งานที่ใช้บ่อย

งานทำอย่างไร
เพิ่มห้อง / ผู้เช่า เปิดทรัพย์สิน → เพิ่มห้อง → เพิ่มผู้เช่า → ตั้งสัญญา → ส่งลิงก์เชิญให้ผู้เช่ากดใน LINE
ออกบิล บันทึกมิเตอร์ (ถ้ามีค่าน้ำไฟ) → สร้างบิล → ส่งผ่าน LINE ให้ผู้เช่า
ตรวจสลิป เปิดรายการสลิปรอตรวจ → ดูรูป + ผล OCR → กดอนุมัติหรือปฏิเสธ
ประกาศลูกบ้าน เข้าเมนูชุมชน → โพสต์ประเภท “ประกาศ” (ปักหมุดได้)
เคล็ดลับ: เริ่มวันด้วยหน้า “ภาพรวม” จะเห็นงานค้างทั้งหมดในที่เดียว ไม่ต้องไล่หาทีละเมนู

3. คู่มือผู้เช่า (ผ่าน LINE)

3.1 ชำระค่าเช่า / ค่าน้ำไฟ

  1. กดปุ่ม ชำระเงิน ในเมนู หรือเปิดบิลจากหน้าหลัก
  2. ตรวจยอดให้ตรงกับใบแจ้งหนี้
  3. สแกน QR PromptPay → โอนเงิน
  4. กลับมาในแอป แล้วกด แนบสลิป
  5. รอเจ้าของอนุมัติ จะได้รับใบเสร็จในเมนูเอกสาร

ภาพตัวอย่างหน้าชำระเงินและแนบสลิป

3.2 เอกสาร (บิล / ใบเสร็จ / สัญญา)

  1. กดปุ่ม เอกสาร
  2. ใช้ชิปด้านบนกรอง: ทั้งหมด / บิล / ใบเสร็จ / สัญญา
  3. แตะรายการเพื่อเปิดดูหรือดาวน์โหลด

บิลที่ยังไม่ชำระจะถูกจัดไว้ด้านบนสุดให้ง่ายต่อการกดจ่าย

3.3 ชุมชนและแจ้งซ่อม

  • ชุมชน — อ่านประกาศเจ้าของ พูดคุย ของหาย ซื้อขายมือสองในกลุ่ม (คอมเมนต์ในแอป)
  • แจ้งซ่อม — สร้างรายการ แนบรูป แล้วติดตามสถานะได้

4. ตรวจสลิปและ OCR (สำหรับเจ้าของ)

เมื่อผู้เช่าแนบสลิป ระบบจะอ่านรูปบนเซิร์ฟเวอร์ของคุณเอง แล้วแนะนำว่ายอดกับบัญชีปลายทางตรงหรือไม่ — คนยังเป็นผู้อนุมัติสุดท้าย

หน้าตรวจสลิป — ดูรูปจริง + สถานะตรง/ไม่ตรง แล้วกดอนุมัติหรือปฏิเสธ

  1. เปิดรายการสลิปรอตรวจจากภาพรวมหรือเมนูบิล
  2. ดูรูปสลิปให้ชัด
  3. ดูบล็อก “ผลตรวจสลิป (OCR แนะนำ)”
    • ยอดในสลิป ตรงกับบิลหรือไม่
    • บัญชีปลายทาง ตรงกับ PromptPay/เลขบัญชีของอาคารหรือไม่
  4. ถ้าดูด้วยตาแล้วยืนยันได้ → กด อนุมัติ
  5. ถ้าผิดยอด / ผิดบัญชี / สลิปไม่ชัด → กด ปฏิเสธ พร้อมเหตุผล
รูปสลิปถูกประมวลผลบนเซิร์ฟเวอร์ของระบบ (ไม่ส่งออกไปบริการภายนอกในโหมดมาตรฐาน) และใช้เป็นคำแนะนำเท่านั้น

5. ประเภทบัญชี และการเปลี่ยนเป็นถาวร

แอดมินกำหนดประเภทตอนสร้างบัญชี หรือเปลี่ยนภายหลังได้จากหน้าจัดการเจ้าของ

ประเภทความหมายเหมาะกับ
ทดลองใช้เริ่มนับวันเมื่อเข้าใช้งานครั้งแรกลูกค้าใหม่ทดระบบ
รายเดือนเปิดสิทธิ์ประมาณ 30 วันลูกค้าจ่ายรายเดือน
รายปีเปิดสิทธิ์ประมาณ 365 วันลูกค้าจ่ายรายปี
ถาวรไม่มีวันหมดอายุ ไม่มีบิลค่าบริการใช้งานเอง / บ้านเช่าของตนเอง

วิธีเปลี่ยน Owner ที่มีอยู่แล้วเป็นถาวร

  1. ล็อกอินด้วยบัญชี แอดมิน
  2. เข้าเมนู เจ้าของ / จัดการเจ้าของ
  3. หาชื่อเจ้าของที่ต้องการ
  4. ที่รายการประเภทบัญชี เลือก ถาวร (ใช้งานเอง)
  5. ยืนยัน — ระบบจะเปิดสิทธิ์แบบไม่มีวันหมดอายุทันที

6. คำถามที่พบบ่อย

ผู้เช่าต้องมี Username ไหม?

ไม่ต้อง — ผูกผ่านลิงก์เชิญใน LINE ครั้งเดียว แล้วใช้เมนูด้านล่างแชท

ชำระเงินแล้วแต่ยังไม่ขึ้นใบเสร็จ?

แปลว่าเจ้าของยังไม่อนุมัติสลิป ให้รอหรือติดต่อเจ้าของผ่านปุ่ม “ติดต่อ”

เมนูใน LINE ยังเป็นปุ่มเก่า?

ให้แอดมินอัปเดต Rich Menu ในหน้าตั้งค่า แล้วให้ผู้เช่าเปิดแอปจาก LINE อีกครั้ง

ชุมชนไม่ขึ้นประกาศ?

ตรวจว่าห้องของผู้เช่าผูกกับเจ้าของคนเดียวกับผู้โพสต์ และโพสต์ไม่ได้ถูกซ่อน

ต้องการความช่วยเหลือเพิ่ม?

ติดต่อผู้ดูแลระบบที่ให้บัญชีคุณ (แอดมิน PropFlow ขององค์กรคุณ)

PropFlow — คู่มือลูกค้า · เปิดไฟล์นี้ในเบราว์เซอร์แล้วกด “พิมพ์ / บันทึก PDF” เพื่อส่งให้ลูกค้าได้ทันที
