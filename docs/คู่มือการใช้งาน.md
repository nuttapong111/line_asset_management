## สรุปสั้นสำหรับการใช้งานภายใน

ดูรายละเอียดขั้นตอนแบบข้อความได้ใน HTML ด้านบน ส่วนสรุปสำคัญ:

| บทบาท | เข้าใช้ที่ | งานหลัก |
|--------|-----------|---------|
| Owner | `/portal/login` | จัดการห้อง ผู้เช่า บิล ตรวจสลิป ชุมชน |
| Tenant | LINE OA Rich Menu | ชำระเงิน เอกสาร ชุมชน แจ้งซ่อม |
| Admin | `/portal/login` | สร้าง/เปลี่ยนประเภท Owner, อนุมัติบิลค่าบริการ |

**เปลี่ยน Owner เป็นถาวร:** แอดมิน → เจ้าของ → dropdown ประเภท → ถาวร (ใช้งานเอง)
